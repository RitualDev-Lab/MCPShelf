# mcpshelf ⚡
> Official Python client & CLI for MCPShelf (https://mcp.ritualdev.in)

## Installation
```bash
pip install mcpshelf
```

Or run directly without installation:
```bash
uvx mcpshelf search secret
```

## Usage

### Search 400+ Verified MCP Servers
```bash
mcpshelf search postgres
```

### Audit an MCP Server Trust Score
```bash
mcpshelf audit io.github.RitualDev-Lab/agentshield
```

### Run as Stdio MCP Server
```bash
mcpshelf-mcp
```
