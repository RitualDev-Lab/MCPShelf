## 💬 Maker Comment (First comment upon launch)

```markdown
Hey Product Hunt community! 👋

I'm thrilled to introduce **MCPShelf** (https://mcp.ritualdev.in) — the open-source registry, trust evaluation engine, and discovery portal for the Model Context Protocol (MCP).

Anthropic's open-sourcing of MCP enabled AI clients like Claude Desktop, Cursor, and Windsurf to connect directly to external databases, filesystems, and developer APIs. But installing and vetting MCP servers is often painful:
- Broken JSON configurations and missed arguments
- Hidden context window bloat where large schemas eat thousands of prompt tokens
- Unvetted stdio sub-processes running with arbitrary workstation privileges

We built MCPShelf to solve this for the developer community:
✨ **1-Click Installs**: Copy-ready configurations and direct deep links (`cursor://` and VS Code) for Claude Desktop, Cursor, Windsurf, Cline, and Zed.
🛡️ **Security & Sandbox Ratings**: Automated privilege scanning for arbitrary shell execution, file writes, and outbound network calls.
⚡ **Token Footprint Calculator**: See the exact prompt token cost of all exposed tools before installing.
🏷️ **Live SVG Badges**: Embeddable badges for server creators to display verification on GitHub.
🤖 **Terminal CLI**: Browse, search, and install right from your shell (`npx @ritualdev-lab/mcpshelf`).

The entire platform is 100% open-source under Apache-2.0, static, and zero-cookie.

We'd love to hear your feedback, thoughts, and feature requests. What MCP servers are powering your agent stack today? 🚀
```
